# Security Policy

## Supported Versions

Python 3.8 and above.
Modern Qiskit (qiskit >= 1.0.0)

| Version | Supported          |
| ------- | ------------------ |
| >= 3.8   | :white_check_mark: |
| < 3.0   | :x:                |
| >= 1.0.x   | :white_check_mark: |
| < 1.0.x   | :x:                |
